# Codex Accounts 0.6.1

适用于安装在 `/Applications/ChatGPT.app` 的 Mac 版 Codex。要求 Apple Silicon Mac、macOS 14 或更新版本。工具运行在菜单栏，不显示 Dock 图标。

## 使用

1. 从“应用程序”打开 `Codex Accounts.app`，或双击桌面的“Codex 账号切换”快捷方式，然后点击菜单栏的双人图标。程序不显示 Dock 图标。
2. 为每个账号填写名称、登录邮箱和 HTTPS 取码网址。
3. 点击“保存桌面授权”，在官方网页登录该账号一次。首次登录可能要求密码与 MFA；同一份授权随后用于桌面切换和额度读取，无需再点第二个授权按钮。
4. 主 Codex 的有效配置必须明确包含 `cli_auth_credentials_store = "file"`；工具通过 `config/read` 检查合并后的配置，遇到 `keyring`、`auto`、`ephemeral` 或无法确认的设置会停止，不会自动迁移凭据。点击“切换到此账号”。工具会关闭主 Codex、保存刚退出时当前账号最新的 `auth.json`、将目标账号的授权文件放到默认 `~/.codex/auth.json`，然后正常重启同一个主应用。切换会中断主 Codex 正在运行的任务，请先保存工作。
5. 点击“刷新”查看各额度窗口、北京时间重置时刻、倒计时及可用重置卡张数。若接口返回卡片明细，还会显示最多三张的到期时间；未返回明细时不会把它们算成 0 张。顶部“打开 Codex”只打开主应用；“取码网页”只打开网址并复制邮箱。

菜单栏不展示服务端返回的 `gpt-reserve` 额度项；常规 Codex 额度和重置卡继续显示。

账号卡片右侧直接提供“编辑”，右上角“…”菜单提供“重新授权”和“从列表移除账号”。授权期间，右侧显示“取消授权”；即使关闭了登录网页，也可点击它立即终止本次后台登录等待。清理完成后解除忙碌状态，取消不会删除旧授权。仅关闭网页不会自动取消，仍保留 5 分钟超时兜底。新登录先在临时目录完成邮箱和授权文件校验，再替换保存的授权；取消、超时或登录错误账号时保留旧授权。看到“新授权已保存，点击切换后应用”后，点击切换，即使是当前账号也会重新启动并应用新授权。

主 Codex 始终使用默认 `~/.codex` 数据目录。工具只替换该目录的 `auth.json`，不移动本地项目、聊天或状态数据库，也不新建第二个桌面实例。若旧版工具开启的独立 Codex 窗口仍在运行，请先退出它。

本机已完成双向切换验证：切回时无需重新输入验证码，原有项目和聊天仍在，主 Codex 保持单实例。长期会话有效性仍取决于官方授权；会话失效时可能需要重新进行官方登录。工具不会自动获取或填写验证码。

## 存储

- 账号名称、邮箱和额度快照：`~/Library/Application Support/Codex Accounts/accounts.sqlite`。
- 取码网址：macOS 钥匙串，不写入数据库。
- 各账号桌面授权：同目录下 `desktop-switch/<UUID>/auth.json`，权限为仅本人读写；切换时将刚退出的主应用授权更新回对应文件。
- 旧版独立额度会话：同目录下 `profiles/<UUID>/codex-home`。新版不要求再次授权；已有会话保留，以兼容尚未保存桌面授权的旧账号。
- 原有本地项目和聊天：默认 `~/.codex`，工具不会移动或合并这些记录。

“从列表移除账号”会移除账号卡片、保存的桌面授权和取码网址；共享 `~/.codex` 内的项目与聊天、旧版独立账号目录都会保留。若移除的是当前桌面账号，主 Codex 不会立即退出该账号。旧版独立额度会话可能仍留在系统钥匙串中；若需彻底清理，应单独核对后处理。

## 构建

在本目录运行 `./build.sh`，输出位于上一级目录的 `CodexAccounts.app`，并自动安装到 `/Applications/Codex Accounts.app`。构建使用 macOS 的 Swift 工具链，并执行本地临时签名。如果安装版正在运行，脚本会在构建成功后关闭旧进程、更新应用并重新打开。

日常启动使用 `/Applications/Codex Accounts.app`。桌面快捷方式始终指向“应用程序”中的版本。只修改源代码不会自动构建；每次改动后需运行一次 `./build.sh`。账号数据存放在用户资料目录中，与应用程序安装位置无关。

## 0.6.0 修复与回归验证

- 编辑、删除、启动、授权和切换有统一的界面状态保护；读取额度期间也禁止修改账号。授权保存、删除、启动、切换和后台文件续期共用目录锁。
- 删除账号会留下不含凭据的 UUID 删除标记，阻止旧实例的排队授权任务重新写回该账号。
- 共用 RPC 接收器先区分服务端请求、通知和响应。外部 token 续期请求会收到明确错误响应，并转入原有续期/重新授权处理；不会当成空额度成功。额度响应缺少额度字段时保留旧快照并显示错误。
- 子进程退出后才释放目录锁和删除临时目录；超时可终止阻塞的临时子进程。
- `./test.sh` 覆盖 RPC ID 冲突、异常响应、额度字段、存储策略、重新授权失败保留旧文件、成功提交、授权与删除竞争、删除后旧任务以及界面操作互斥。`./test.sh --integration` 额外在空临时目录中验证随附 CLI 的 `config/read` 协议。
- 本次完成隔离回归测试及构建，不包含真实账号退出、切换、在线续期或主应用界面身份验证。启动成功只表示授权已替换并发出启动请求，实际账号仍需在主应用内核对。工具锁只能协调本工具的操作，无法阻止用户从 Finder、Dock 或其他程序启动主应用；提交前会再次检查进程。

## 历史验证与限制

已在 macOS 27.0.1、Codex 桌面版 26.928.20755 上确认：菜单栏工具已完成双向实际切换；项目与聊天保留，切回时无需验证码。桌面授权可用于读取额度，读取后授权文件内容未改变。0.5.0 已完成本机编译、重置卡字段解析测试和实时只读核验；双向切换的用户验证针对早期 0.3.0 版本。

额度读取使用 OpenAI Docs 所述的临时外部 token 模式：只向临时 App Server 提供 access token，不传入或复制 refresh token。当前账号的凭据刷新由主 Codex 负责；非当前账号在额度读取需要续期时，可在受锁保护的原授权目录内由 Codex 刷新。若官方会话失效，仍需重新登录。该外部 token 接口目前在 OpenAI Docs 中标为实验性。

重置卡统计来自 `account/rateLimits/read` 的 `rateLimitResetCredits.availableCount`。该字段由服务器提供时才显示；为 `null` 或缺失时显示为未知，不会推断为 0。`credits` 明细可能缺失或被截断，到期时间仅按实际返回的明细展示。工具不会调用使用重置卡的接口。

取码网页目前只提供按账号打开网址与复制邮箱，尚未自动填写网页或读取验证码。旧版独立实例内后来产生的本地记录不会自动合并到默认目录。
